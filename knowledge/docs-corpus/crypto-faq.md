### Can I start trading with purely Crypto in my Gemini account?

Yes, you are able to use the Arbitrage Algorithm with only crypto in your Gemini account. When setting up an instance, make sure to back-date the start date to atleast 1 year in the past. Keep in mind that only sell orders will execute until you have accrued enough cash to fill a buy order.

### TradingView said an instance executed, but I am not seeing a trade in my Gemini transaction history.

* Ensure that your Gemini account is funded with the same currency your chart is set to (USD, USD, GUSD)
* Ensure that your chart is set to the correct currency pair before creating your instance. For example, if your chart is set to BTC/USDT, you will need to have USDT in your Gemini account. Likewise, if you are setting up an instance on a BTC/USD chart but only have USDT, the instance will not execute.

### Can I connect multiple Gemini accounts to The Bitcoin Algorithm(s)?

Yes, you are able to create an API key for each Gemini account and connect it to Arch Public allowing you to set up instances across personal and tax savings accounts.(for example, self directed IRA retirement accounts).
